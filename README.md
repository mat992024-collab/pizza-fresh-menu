# منيو بيتزا فريش

منيو إلكتروني بالعربية (RTL) للطلب عبر واتساب. موقع ثابت بدون سيرفر، جاهز للرفع على GitHub Pages.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `css/style.css` | الأنماط والألوان |
| `js/app.js` | منطق المنيو والسلة والفاتورة ولوحة الإدارة |
| `data/menu.js` | **كل البيانات**: الأقسام والأصناف والأسعار ومناطق التوصيل والإعدادات |
| `assets/logo.webp` | الشعار |
| `.nojekyll` | يمنع معالجة Jekyll على GitHub Pages |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد في الجذر (بما فيها `.nojekyll`).
2. من Settings ثم Pages اختر Deploy from a branch، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة يعمل الموقع على `https://USERNAME.github.io/REPO/`.
4. اصنع QR Code لهذا الرابط وضعه على الطاولات أو القائمة.

## إدارة المنيو من الموقع

1. افتح الموقع، واضغط "دخول المدير" في أسفل الصفحة، واكتب إيميلك أول مرة لتسجيله.
2. من "إدارة المنيو" عدّل الأسعار والأصناف والأقسام والمناطق ورقم واتساب والشعار.
3. من الإعدادات أدخل بيانات GitHub (المالك، المستودع، الفرع، الرمز).
4. اضغط "نشر التعديلات". يُحدّث الموقع ملف `data/menu.js` تلقائياً.

### إنشاء رمز GitHub (Token)

1. GitHub ثم Settings ثم Developer settings ثم Personal access tokens ثم Fine-grained tokens.
2. Repository access: اختر مستودع المنيو فقط.
3. Permissions ثم Contents: Read and write.
4. انسخ الرمز وأدخله في إعدادات لوحة الإدارة. يُحفظ في متصفحك فقط، ولا يوضع في أي ملف.

الإيميل في لوحة الإدارة لا يمنع أحداً من فتحها، فالحماية الفعلية هي الرمز. من لا يملكه لا يستطيع حفظ أي تغيير. استخدم رمزاً لمستودع المنيو فقط، ولا تحفظه على جهاز مشترك.

### بدون رمز

اضغط "تنزيل menu.js" من الإعدادات، ثم ارفع الملف يدوياً إلى مجلد `data` في المستودع.

## إعدادات في الكود

أرقام واتساب والدفع والأسماء كلها في `data/menu.js` ويمكن تعديلها من لوحة الإدارة. رقم واتساب يكتب بالصيغة المحلية (01xxxxxxxxx) ويتحول تلقائياً إلى الصيغة الدولية.

## ملاحظات

- رقم الفاتورة (`inv-1`, `inv-2`…) يُحفظ في متصفح كل زبون، لذلك يبدأ كل زبون جديد من `inv-1`.
- واتساب لا يسمح بإرفاق صورة تحويل تلقائياً، فيرسلها الزبون يدوياً داخل المحادثة.
- الخطوط من Google Fonts وتحتاج اتصالاً بالإنترنت.
